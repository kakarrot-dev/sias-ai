# 聊天 MVP：后台模块收敛（前序记录）

日期：2026-09-17。当前 worktree：`AI Employee OS-web-admin`。

> 后续范围已修正：用户明确需要单专家配置 Skill、Tool、MCP、模型及输入输出。能力中心现已恢复，保存和发布不再清除执行能力与格式设置。以下纯文字聊天投影和五模块限制为前序实现记录，不作为当前要求；请以[专家能力配置记录](2026-09-17-expert-capability-mvp.md)为准。

## 当前目标

系统管理员创建并发布专家 → C 端用户统一登录 → 选择专家进行文字聊天。

本次完成后台浏览器交互原型的收敛。使用既有 Campus Agent、版本、事务存储、用户中心和会话统计，不新增第二套专家或模型数据。

## 模块与页面

| 模块 | MVP 展示 | 暂不开放 |
| --- | --- | --- |
| 总览 | 可用专家、正常用户、示例会话和已上报 Token；待发布草稿；管理员发布至用户聊天的流程；合并智能体、用户和系统管理审计 | 共享能力数量、团队和业务任务快捷入口 |
| 智能体中心 | 只列普通专家；名称／简介、模型、发布状态／版本、更新时间；搜索和状态筛选；聊天配置、发布记录、会话与用量 | 数字助理、专家团、队长、部门、责任人分配、演示角色切换、逐个专家授权 |
| 用户中心 | C 端账号列表、身份详情、启停和本人会话／用量跳转 | 部门、角色管理、权限矩阵 |
| 运行中心 | 会话元信息、回复异常、模型用量和管理审计；保留既有详情弹窗 | 任务执行、审批、业务结果；聊天正文查看 |
| 系统设置 | 平台名称；OIDC 身份接入说明；与专家配置同源的模型目录；真实服务接入状态 | 分类维护、另一套模型配置、假连接检查、客户端密钥输入 |

能力中心从主导航撤下，`/capabilities` 关闭。`/legacy-agents` 及子路径关闭，避免旧配置流程重新暴露业务能力。既有业务中心、团队和队长入口保持关闭。历史数据及审计保留，不在浏览器加载时自动改写。

## 专家字段合同

| 页面字段 | 数据 | 规则 |
| --- | --- | --- |
| 专家名称 | `Config.name` | 2–20 字；未删除普通专家之间唯一 |
| 专家简介 | `Config.description` | 发布必填，最多 200 字 |
| 聊天模型 | `Config.model` | 来自 `campus/model.ts` 的唯一目录；发布须选择有效且启用的模型 |
| 系统提示词 | `Config.prompt` | 发布必填，最多 8000 字；描述咨询专长、回答要求与边界 |
| 开场白 | `Config.opening` | 选填，最多 200 字 |
| 推荐问题 | `Config.expert.questions` | 选填，最多 4 条，每条最多 80 字 |

名称有效即可保存未完成的草稿，简介、提示词、模型齐备后发布。稳定专家 ID／key 由系统生成，已创建标识保留，不作为用户填写项。页面预览直接使用当前表单数据，只展示开场内容，不生成模型回复。

`chatConfig` 在明确保存或发布时生成聊天配置：`mode=chat`、文字输入／文字回复、无用户表单、附件、工具、Skill、MCP、人工确认节点或多人交付；生成参数采用固定默认值。部门和 owner 仅作为既有类型的兼容数据保留，不作为聊天发布条件。旧的高级草稿设置会在本次明确保存／发布时被替换，页面给出提示；既有发布快照不改写。历史版本回退后，未来服务端仍只能消费当前 MVP 允许的聊天字段，不能激活旧工具或业务执行参数。

## 状态和交互

- 所有专家变更在原型操作层校验 `actor.role === admin`。旧配置人员、发布人员、审计人员或 C 端身份不能创建、保存或发布。此为原型约束，不能代替生产服务端鉴权。
- 草稿仅管理员配置；编辑已发布专家不改变当前快照。先保存再发布，新会话使用新版本，原版本仍可查看。
- 发布弹窗展示专家、模型、发布内容和使用范围，并记录发布说明。
- 停用要求原因；停止接受新的聊天请求，历史会话、用量和旧业务记录保留。启用恢复当前发布版本，不自动重发请求。
- 发布记录的详情展示版本资料、提示词、开场白、推荐问题、发布人／时间／说明。回退要求原因，保留当前草稿和其他版本。
- 正常、有效身份的 C 端账号可使用已发布且启用的普通专家；不设逐个授权。不允许使用助理、队长或专家团。
- 保存中的并发点击由既有锁阻止；存储失败保留输入。持久化成功而页面读取失败时关闭操作弹窗，允许重试读取，避免重复发布。
- 未保存草稿在当前标签页暂存，离开时可保存或放弃；刷新保留已存配置。
- 总览最近操作与运行中心管理审计使用同一数据源，包含用户启停，不再跳入旧编辑器。

## 真实接入仍需完成

1. 服务端 OIDC 回调、登录会话和账号建立；使用 `iss + sub` 对应平台用户 ID，不将 C 端用户授予后台管理权限。
2. 管理员认证及服务端专家管理、版本发布接口；C 端只读取已发布且启用的专家展示资料，不返回系统提示词或凭证。
3. C 端登录、专家列表和聊天页面；服务端验证账号与专家状态，再加载发布配置和模型连接，处理流式回复与停止。
4. 持久化会话／消息及唯一模型调用记录，上报用量和异常。后台延续元信息和用量视图，不因本次改版添加正文查看入口。

当前无真实模型调用、登录回调或 C 端页面接入。模型、用户、会话与用量都是明确标注的示例；管理员的原型操作保存在当前浏览器。
