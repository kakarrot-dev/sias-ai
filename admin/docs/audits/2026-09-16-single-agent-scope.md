# 智能体中心：暂时收敛到单个智能体

日期：2026-09-16。

用户要求先禁用专家团与队长 Agent，不可创建、不可展示，先处理单个智能体场景。

## 当前行为

- 智能体中心保留数字助理与普通专家；专家团页签、队长角色筛选和两类对象的列表记录、计数、创建选项均隐藏。
- “创建”直接进入普通专家表单；旧 `/agents/new` 与 `/agents/manual` 入口仍可创建普通专家。
- 专家团、队长的旧创建链接和已存在对象的详情、编辑、发布、历史链接只显示“当前仅开放单个智能体”，不加载配置或操作控件。
- Action 层同样拒绝两类对象的创建、保存、复制、发布及其他管理操作。混合批量操作在修改前整体拒绝；使用判断也拒绝新请求。
- 单个专家的发布摘要不展示专家团引用入口。新建或复制普通专家默认允许独立使用，仍不自动授予任何人员权限；既有普通专家的使用方式与授权保持原值。
- 原有队长、专家团、固定版本引用、发布快照及业务记录保留，不删除或迁移，统一由 `availability.ts` 中关闭的功能开关控制当前可用范围。

本次只修改后台智能体中心的当前原型范围。其他模块的早期示例、用户前台、桌面 Runtime 与真实业务执行不在本次范围。

## 验证

- 改动前新增的范围验收出现 22 项失败、2 项通过，覆盖旧入口仍开放、创建和复制未拦截、发布摘要暴露团队引用等行为。
- 改动后范围验收 25 项全部通过，包含隐藏与直达链接、Action 拦截且不落账、保存刷新、单专家模拟发布／授权／新版本／复制，以及旧数据完整保留。
- 后台原有测试与范围验收合并运行：21 个文件、327 项通过；随后新增单专家发布及版本验收，范围测试 25 项再次全部通过。原有多智能体工作流测试显式启用关闭的功能分支，保留未来恢复时的回归覆盖；当前范围测试使用默认关闭配置，没有覆写开关。
- `admin:build` 通过，包含 TypeScript 检查；现有主入口体积提示仍在。`git diff --check` 通过。
- 真实浏览器在独立端口 5186 验证：列表无队长或专家团；“创建”直接打开普通专家；保存“单智能体验收样例”并刷新后保留；旧专家团创建链接和已有队长编辑链接均显示拦截页；1280×720 下列表和拦截页显示正常。

以上证明浏览器原型中的创建、管理、展示限制和单专家配置流程；不代表接入真实底座、模型或业务系统。
