# 专家团输入输出归属调整

> 历史记录：本文团队独立输入输出及四步创建方案已根据用户纠正撤回。当前以[专家团组队边界修正](2026-09-16-team-assembly-boundary.md)为准；保留本记录用于追溯。
## 已确认方案

- 专家团拥有用户表单、资料限制、缺失处理、成果格式、模板、校验和完成条件。
- 队长创建为基本信息、协作能力、检查配置三步；已保存队长保留运行配置，随团队发布，不独立配置用户交互。
- 队长接收团队任务、上下文及成员结果，执行分派、汇总和状态管理。业务输入输出在团队中维护一份。

## 数据与兼容

沿用 Config.interaction 与 definition.task，不新增字段配置副本。team.contractVersion 标明团队已经接管约定。新团队默认接管；旧团队只读投影其固定队长版本的输入输出，下次显式保存到团队。已有团队自有交互配置优先保留。历史团队及队长发布快照不改写；队长旧字段保留为兼容来源，不再作为新团队的发布门槛。

团队创建、保存、复制、基于历史版本创建草稿、发布快照、版本读取和差异比较使用同一解析规则。团队换队长不能覆盖已接管的配置。团队缺失材料转人工与多模态输入须核对所引用队长的执行能力。

## 验收标准

1. 队长创建三步，编辑及旧输入输出链接不再提供独立表单编辑。
2. 专家团创建、编辑均可配置输入与交付，保存重开保留，预览使用团队配置。
3. 团队发布校验与发布差异覆盖表单、成果和完成条件；旧队长无效业务表单不阻断协作配置。
4. 旧团队使用固定版本回填；保存后修改或更换队长不改变团队约定；复制与历史快照可追溯。
5. 类型检查、相关测试、构建及浏览器创建/编辑/发布验证通过。

## 实现与验证结果

修复前已复现 `managedConfig` 清理团队时丢弃 `interaction` 和完成条件的问题。现在复用已有输入输出组件，团队配置保存到原 Config 字段；发布摘要仅列团队可配置的内容。队长导航与旧输入输出链接进入协作能力，提供所属团队入口。协作 Skill 示例明确接收团队约定、任务上下文和成员结果，返回成果、状态、未完成事项与证据。

- 自动验证：19 个测试文件、298 项通过；包含团队表单及回执保存重开、只读详情、发布缺项定位、固定版本兼容读取、复制、基于历史版本建草稿、团队及队长共同发布、回退快照保持不变。无效旧队长业务表单不再阻断队长；多模态与转人工仍核对固定队长配置。
- 类型检查、生产构建与 `git diff --check` 通过。Vite 仍提示现有主包超过 500 kB，本轮未进行无关拆包。
- 浏览器：队长三步创建；旧 `/agents/captain/edit/input` 显示协作能力并可前往所属团队；旧已发布团队展示兼容来源且配置只读。
- 实际创建临时团队：设置“先填写表单”、自定义标题、必填办事主题、可编辑文档和 OA 回执条件；保存、刷新后保留。删除回执来源后，发布按钮禁用；点击错误进入“输出与完成条件”。
- 视觉核查：1440×1000 的团队创建表单以及 1280×800 的团队编辑页，编辑区与试填预览分栏清晰，无横向溢出；创建操作集中排列。所检页面控制台无 warning/error。
- 临时验收团队已通过产品的草稿删除操作移除；未发布或授权测试对象，原有团队与队长未写入修改。

边界：仍是浏览器本地持久化的管理原型。表单试填执行校验；没有接入真实模型调度、业务提交或 OA 回执核验。真实运行端需读取任务固定的团队配置，执行同一完成条件。

## 后续修正：队长协作能力页面

用户指出第二步仍不符合队长职责。浏览器复现：主界面复用普通专家的“技能”列表，展开后出现禁用的账号、资料范围、启用和移除控件，页面把内置执行细节误作待配置内容。原表单输入输出说明还占据首屏重点。

改为队长专用布局：

- 先展示分派固定成员、获取成员状态与结果、汇总本任务结果三项协作职责；名称来自原有能力目录，规则原文仍按固定版本只读查看。
- 将协调模型、按需人工兜底放在“协调设置”；异常处理文案使用“成员执行结果未知”，并说明业务权限与确认规则仍归成员。
- 团队配置归属作为辅助说明，已绑定队长可直达所属团队输入与交付页。
- 只读队长沿用相同结构，模型显示已保存值，接管设置不可更改；旧扩展配置保留核对与移除入口。普通专家的技能及工具配置不变。

验证：先保留缺少队长流程说明的失败回归，再完成修复。19 个文件、300 项自动测试通过；构建含类型检查通过，差异格式检查通过。新增覆盖协作流程、无禁用业务工具表单、规范原文、协调模型及人工兜底保存重开、只读禁止修改。浏览器验证三项职责、展开人工接管、规范只读弹窗与返回原页；1280×800 无横向溢出。临时开关已恢复，未创建或发布测试对象。本次调整展示与配置入口，不新增执行引擎或协作策略。
