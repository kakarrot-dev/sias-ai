# 专家团只负责组队

## 决策来源与边界

用户明确纠正：专家团按照加入的智能体工作，输入输出在智能体设置，专家团就是“组队”。此前引入团队独立用户表单和交付约定超出了这一边界，撤回该设计。

- 普通专家：配置自己的业务输入字段、用户表单、附件要求、输出形式、模板与完成条件。
- 队长：负责分派、收集成员状态与证据、汇总结果；依据本次实际分派成员的输入输出规范协调，不增加团队表单。
- 专家团：维护基本资料、队长、普通成员及固定版本引用，保留发布与使用授权管理。
- 成员加入团队不复制其配置。成员发布新版本后，团队显式更新引用才采用新配置。

## 修改

1. 创建恢复为“基本信息 → 队长与成员 → 检查团队”三步，保留本轮已完成的视觉层级、多选弹窗、暂存及缺项定位。
2. 创建、详情、检查和版本查看移除团队独立输入输出；旧 input/output/io 链接展示成员列表。
3. 删除队长配置投影为团队表单的转换逻辑。新团队不生成 interaction、definition 或契约标记。旧团队字段保留兼容数据，不进入当前配置、校验或发布变更摘要；不改写历史版本。
4. 团队保存校验基本资料，发布校验角色、人数、专属队长、固定引用及依赖。普通专家的表单、附件和业务完成条件仍在专家配置与发布中校验。
5. 队长协作说明、只读示例、需求文档和测试同步修正。旧设计审查记录标为已被替代，保留追溯。
