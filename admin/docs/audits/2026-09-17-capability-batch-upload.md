# 能力中心批量上传原型

范围：仅前端交互原型，不新增后端服务、数据库、执行器或真实 MCP 连接。文件在当前浏览器中解析和保存。

## 页面与交互

- 能力中心右上角提供“批量上传”，不提供表单创建；保留类型、用途和关键词组合筛选。
- 支持多选、拖入多个文件或 ZIP 包，并提供可下载的三类能力示例包。
- 解析预览展示来源、名称、版本、类型、用途及结果。默认勾选有效项，可取消选择；失败和重复项单独提示，不阻止添加其他有效项。
- 同类型、标识及版本重复时跳过，不覆盖已有定义。更新内容需提供新版本，不改写旧发布快照。
- 确认添加后进入统一能力目录；详情可查看上传定义及 Skill 文本文件。智能体配置可搜索、选择、保存和模拟发布，刷新后保留。
- 浏览器存储失败时回滚；保存后读取失败只重试读取，避免重复添加。非系统管理员不展示上传入口。

## 上传格式

| 类型 | 文件与最小字段 | 原型行为 |
| --- | --- | --- |
| Skill | Markdown 包含 YAML frontmatter 的 `name`、`description` 和非空指令正文；支持 `version`、`purposes`、`tags` | ZIP 中每个 `SKILL.md` 形成一项能力，保留其目录下的 UTF-8 文本附件；脚本只作为文本保存，不执行 |
| Tool | JSON：`type: tool`、`name`、`description`，可附 `inputSchema`、`outputSchema`、`handlerKey`、`write`、`idempotent` | 展示工具定义并用于配置选择；兼容 OpenAI `type: function` 定义，不安装处理器 |
| MCP | JSON：`type: mcp`、`name`、`description`、`server`；或标准 `mcpServers` 对象 | 保存 URL 或 command/args；附带 `tools` 定义时可选择具体操作；只有连接配置时显示“待补充工具定义”，暂不可绑定 |

JSON 支持单对象、数组或 `{ "capabilities": [...] }` 批量清单。用途使用 `purposes` 文本数组，继续沿用现有分类筛选。示例包展示完整字段格式。

- 每批最多 30 个上传文件、100 项能力，单文件 1 MB、每批 4 MB，解压内容也受限；ZIP 最多 100 个文件和目录。
- Skill 的工具声明仅保留为数据，不自动授权；需要的 Tool / MCP 在智能体中单独选择。
- Tool / MCP 未声明 `write` 时按写操作展示约束，启用写操作须沿用执行前确认配置；这只是原型校验，不代表生产权限控制。
- MCP headers/env 只接受 `${ENV_NAME}` 引用，不接收明文凭证。原型不访问地址、不运行命令、不进行工具发现或连通性检查。
- 不支持的类型、非法路径、无效 UTF-8、格式缺失和重复项给出明确错误；Skill 包仅保留文本附件。

## 验收证据

- 后台全量测试：26 文件、436 项通过；类型检查与生产构建通过，保留已有入口体积提示。
- 最终 17 项专项测试通过，覆盖混合 ZIP、三种能力、文件保留、错误隔离、重复跳过、保存回滚、版本冲突、刷新、智能体选择与发布、未补充工具的 MCP 限制、写工具确认和只读身份；最终类型检查与差异格式检查通过。
- 浏览器 `127.0.0.1:5186` 实测：混合 ZIP 加一个错误 JSON 解析为 4 项，其中 3 项可添加、1 项失败；成功添加后刷新仍保留。再次上传同 ZIP 显示 3 项重复，确认按钮禁用。
- 浏览器创建“批量上传验收专家”，选择导入的 Skill、Tool、MCP 操作，保存并模拟发布 v1；刷新后 3 项配置及发布状态保留。
- 1280×720 下预览列表内部滚动，确认按钮保持可见。

以上证据仅对应浏览器原型，不代表真实工具执行、模型调用或服务接入。
