# 用户中心与运行中心：双 Key 来源原型设计

依据：用户提供的 `OIDC_API_KEY_MODEL_INTEGRATION(1).md`（核对日期 2026-09-17）。用户确认同时保留平台统一 Key 和用户专属 Key，且仅需前端原型。

## 产品边界

- OIDC 仅建立登录身份；本地用户 ID、OIDC 身份和 Token超市业务账号分开。第三方委托 Key 管理尚未开放，后台不提供代用户建 Key、自动选取第一个 Key、获取完整密钥或交换业务令牌的入口。
- 平台模式由平台 Key 承担调用；个人模式由用户明确授权的专属 Key 承担调用。页面的来源切换仅切换查看内容，不修改用户的付费选择；失败时不自动换来源、模型或分组。
- 管理员配置专家模型；个人 Key 可见模型不能覆盖专家配置。调用前需满足专家模型可见、协议兼容、Key 状态与额度等条件；模型发现成功不等于推理成功。
- 本轮新增均为脱敏示例，只读展示两种方式、状态和统计，不接 OIDC、业务 API、模型网关、真实费用或后端。

## 页面设计与验收标准

| 模块 | 列表 | 详情与交互 |
| --- | --- | --- |
| 用户中心 | 本地用户、身份绑定、账号状态、当前调用来源、模型接入状态、最近登录；按账号状态、来源、接入状态筛选 | 基本信息、模型接入、额度与用量三个分区。平台与个人方式分别查看；展示脱敏 Key、分组、有效期、模型发现和处理指引；保留账号启停及会话跳转 |
| 运行中心 | 会话记录、模型调用、用量统计、管理审计 | 模型调用按时间倒序，按来源、模型、状态筛选，详情展示当次 Key / 分组 / 模型快照、Token、费用、实际费用、错误和建议；不展示聊天正文或重试按钮 |
| 用量统计 | 本平台调用汇总与 Key 上游统计独立查看 | 本地会话 Token 不能当全账号统计；平台共享 Key 不显示为某位用户的个人用量；个人 Key 的累计、指定日期和服务端今日摘要分别标注口径 |

## 额度与用量口径

- 钱包余额、Key 剩余额度、订阅剩余额度分别命名，使用响应单位，不混加、不推算现金扣款。
- Key 累计用量按 `usage.total`；指定日期按 `daily_usage` 对应时区的数据；`usage.today` 单独标注服务端今日摘要，不冒充选择日期或最近 24 小时。原型使用明确标注的固定示例日期。
- `cost` 与 `actual_cost` 分列；统计缺失显示“未提供 / 暂不可用”，真实 0 仍显示 0。失败或停止的已上报消耗继续保留。
- 账号业务授权不足时，全账号余额和用量显示未授权；允许 Key 响应展示的钱包余额也不意味着可枚举账号 Key 或读取全账号用量。
- Key 过期、停用、额度耗尽与统计接口可读取是不同状态；不以 `isValid` 或模型列表存在判断可调用。

## 异常展示

状态设计包含未连接、授权撤销、Key 过期、额度耗尽、模型列表为空或读取失败；本轮示例覆盖未连接、过期、额度耗尽、空模型、504 超时及用量缺失。无 Key 时引导用户在 Token超市创建专属 Key 并主动授权；“已有但不可用”不等同于“没有 Key”。用户停用不撤销上游 Key，OIDC 退出不使 Key 自动失效。401 / 403 / 429 等正式接入错误处理仅为后续契约，不伪造为已经联调通过。

验收以字段口径、来源隔离、筛选/详情/跳转、既有账号管理保持、浏览器展示和类型检查为准；不验证真实调用或生产授权。

## 本轮验收结果

- 27 个测试文件、445 项测试通过；后台原型 TypeScript 检查和 Vite 构建通过。构建保留已有入口体积提示。
- 新增 7 项原型测试覆盖来源查看不修改配置、Key 用户隔离、三类额度、零值与缺失、日期/时区变化、调用快照归属、用户到调用记录跳转和查看权限。
- `127.0.0.1:5186` 浏览器验证用户列表、三分区详情、上海/UTC 切换、模型调用平台来源筛选、失败详情、本平台费用汇总及个人 Key 上游统计。过期 Key 仍显示历史用量，不能据此认为可推理。
- 1280×720 检查用户列表、用户详情及运行中心用量表格，内容按页面或弹窗滚动，无整页横向溢出。
- 新增实现仅位于 `src/admin` 的组件、样式和脱敏示例，无后端路由、网络调用、密钥输入或凭据存储。保留本地用户和已有会话示例，不改写历史用户数据。
