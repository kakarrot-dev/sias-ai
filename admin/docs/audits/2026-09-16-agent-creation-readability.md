# 智能体创建页可读性修复

## 范围与问题

`web-admin` 分支的普通专家、队长创建流程，以及复用的输入输出编辑页。原页面存在重复步骤标题、说明文字偏小、嵌套卡片过多、操作分散的问题。步骤条固定在 76px，而页面标题未固定，切换步骤时会遮住当前标题。

## 调整

- 基础信息和工作能力使用 820px 阅读宽度；输入输出保留配置与预览两列。
- 步骤条改为数字进度与下划线，当前步骤使用标题和一行说明。首次填写不提前展示待完善标记。
- 减少重复标题、空状态边框和说明；模型、技能、工具按职责分组，队长使用单独的协作技能说明。
- 输入文字 15px、字段标签 14px、辅助说明主要为 13px；提示词使用与页面一致的中文字体。
- 创建页保存操作集中在底部，主按钮明确标注“下一步：工作能力 / 输入与输出 / 检查配置”，最后一步只提供一个创建动作。
- 输入输出保留字段、附件、缺失处理、模板、校验和完成条件。取消输出页外层重复标题，预览入口与表单标题对齐，放大检查页摘要。
- 步骤条固定在顶部，步骤标题滚动位置留出间距，预览面板避开导航与底部操作条。

## 验证

- 类型检查通过；18 个测试文件、288 项测试通过。
- 生产构建通过，仍有既有的 bundle 体积提示。
- 浏览器检查普通专家四步、队长基础信息和工作能力；1440×1000、1280×800 无横向溢出。
- 1280×800 切换后步骤标题位于 88px，导航下沿为 64px；底部主按钮在视口内。
- 表单快速添加“办事主题”后实时展示；空白提交触发必填提示，填写后显示通过校验的输入摘要。
- 浏览器未出现 warning / error。验收临时修改已通过“放弃修改并离开”清理，未新建或发布测试对象。
- 本次为后台原型界面调整，未增加真实模型或业务执行能力；代码未提交或推送。
