# C 端用户中心 MVP

日期：2026-09-17。入口：`#/users`。本轮以用户最新要求“可以登录使用为主，先不做复杂权限设置”为准，取代此前三页签的角色权限方案。

## 当前产品规则

登录身份有效、账号正常，即可使用已发布且未停用的普通聊天智能体及数字助理。不需要角色分配、功能权限配置、个人智能体授权或授权同步。未登录、身份绑定撤销、账号停用、智能体未发布或停用时仍不能使用。专家团和队长继续不开放。

这里的登录状态判断是本地原型的账号资格预览，真实服务端必须校验登录会话。C 端登录不授予后台管理权，后台仍沿用独立的原型操作身份。

## 用户列表与详情

- 用户列表只保留用户 ID、展示名、登录来源、账号状态、注册时间、最近登录及详情入口；支持 ID／名称搜索和状态筛选。
- 顶部统计只保留总用户、正常账号、停用账号；撤下角色管理、权限查询、角色分配与角色筛选。
- 详情显示只读身份信息、使用状态、统一使用范围、本人会话和用量、身份关联信息与操作记录。
- 账号启用／停用必须填写原因，保存刷新后保留并写入管理审计。停用保留身份和历史；重新启用无需补配角色或授权。
- 管理员可执行账号启停；其他演示操作身份只读。配置人员不通过用户详情获取会话与用量。
- 保留本人会话／用量跳转，继续使用统一用户 ID 关联记录。

## 智能体联动与兼容

- 从配置导航撤下“使用授权”和“谁能使用”；旧授权链接显示发布管理页，不再提供授权表单。
- 发布页统一说明“正常用户登录即可使用，无需单独授权”。未发布配置不开放使用，发布快照、回退和停用逻辑继续保留。
- 旧角色、角色绑定、部门／个人授权、内部使用方式及授权同步状态不参与当前 C 端使用判断；旧同步失败不阻塞发布或回退。
- 旧配置和操作审计仍保留在存储中，不做破坏性迁移；新示例不再创建角色和绑定。角色和逐人授权写入操作在当前 MVP 被拒绝。
- 复用原 `PrototypeStore`、用户目录、账号启停审计及会话用量来源；失败回滚、过期版本和保存成功后读取失败的处理继续有效。

## 真实接入边界

当前仍是浏览器本地原型，未实现 OIDC 回调、后端会话、Token 校验或真实聊天请求。身份字段及后端接入要求沿用 [OIDC 排查](2026-09-17-c-user-oidc-fields.md)。本次交付是 MVP 展示和使用规则的收敛，不代表已经能通过真实身份提供方登录。
