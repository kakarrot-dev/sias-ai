## 最新页面精简

按用户截图反馈：删除“发布到用户前台”和“聊天入口预览”整块展示及底部保存栏。取消、保存草稿、发布专家统一置于标题右侧；取消沿用未保存提醒，保存与发布仍使用原版本流程。启停／删除草稿保留在状态行。

输入输出页同时展示两组格式选项，均可多选：输入为文字、文档、表格、图片、音频；输出为纯文本、Markdown、Word 文档、PDF、JSON、表格（CSV）。取消内层页签、填写表单、附件限制编辑、模板、章节、成果字段、事实核对和交付确认设置。输出至少保留一种；输入未选择时可暂存但不能发布；多模态输入仍检查模型匹配。JSON 不再要求填写结构化字段。

既有高级输入输出数据保留在草稿与历史快照中，不在本次编辑、详情页面展示，也不作为当前 MVP 的发布前置条件。格式修改只更新格式字段，不清空原有数据。模型、Skill、Tool、MCP 和工具执行前确认设置继续保留。

本轮验收：24 文件、396 项测试通过；类型检查和构建通过（保留入口体积提示）；浏览器使用既有“能力配置验收专家”保存并发布 JSON 格式为 v2，刷新后保留，验证取消／放弃修改返回列表；检查 1280×720 和 1024×768 版式，无整页横向溢出，本轮操作无控制台错误。`git diff --check` 通过。

## 范围修正

用户明确需要智能体配置 Skill、Tool、MCP、运行模型以及输入输出格式。当前目标为：管理员配置并发布单个专家，C 端用户登录后通过对话使用专家，专家根据已发布配置处理输入、调用能力并输出结果。

“最小 MVP”限制的是组织、角色、组团和配置复杂度，不应自动删除单专家所需的执行能力。此前纯文字聊天版本的 `chatConfig` 投影会重建配置、清空绑定并重置模型与格式；本次替换为保留配置的 `expertMvpConfig`。前序记录见[聊天 MVP 收敛](2026-09-17-chat-mvp.md)。

保留六个一级模块：总览、智能体中心、能力中心、运行中心、用户中心、系统设置。能力中心重新提供既有资源目录；业务中心、数字助理、队长、专家团、部门和复杂角色配置继续不开放。创建、保存、发布、启停等操作仍仅允许系统管理员。正常登录的 C 端账号可使用已发布且未停用的普通专家。

## 页面与字段

| 配置分区 | 可配置内容 | 数据来源 |
| --- | --- | --- |
| 基础与提示词 | 名称、简介、系统提示词、开场白、推荐问题 | 既有 Campus `Config` |
| 模型配置 | 运行模型、最大输出 Token、响应超时、流式回复；展开生成参数调整温度与 Top P | `campus/model.ts` 同源模型目录与模型参数 |
| 执行能力 | Skill、内置 Tool、MCP 服务及具体操作；绑定版本、允许动作、调用身份、资料范围、执行前确认 | 既有 `capabilities.json`、`Config.tools`、`Config.nodes`，复用统一能力选择器 |
| 输入输出 | 输入类型：文字／文档／表格／图片／音频；输出格式：纯文本、Markdown、Word、PDF、JSON、CSV，均可多选 | `Config.interaction` 为输入输出事实源；保存时派生兼容 `input`／`output` |

- Skill 是工作方法及其工具依赖；管理员启用所需工具。MCP 按具体操作选择，不能仅保存一个空服务绑定。
- 写操作保留发起用户确认；无幂等保障的写操作不允许自动重试。调用身份与资料范围配置不等于已获得真实凭证或服务授权。
- 输入输出只配置格式；当前仅向发起用户返回结果，不开放表单和多人交付设置。
- 原型中的 PDF／文档／JSON 等选项保存的是输出约定，不代表已实现文件生成器或服务端结构校验。
- 发布摘要显示模型、输入格式、输出格式及绑定能力。发布版本详情增加模型参数、能力版本、已启用动作、调用身份、确认规则、输入格式和输出格式。

## 保存与发布规则

1. 保存允许未完成草稿，但已填模型参数、格式选项和数值范围必须有效。名称仍为 2–20 字且普通专家之间唯一；发布要求简介、提示词与可用模型齐备。
2. 发布检查能力与版本可用性、Skill 必需工具、MCP 连接及操作、写操作确认、自动重试限制；图片／音频输入须选择支持多模态的示例模型；JSON 输出仅约定格式，不再要求声明字段。
3. 普通专家不再因历史部门绑定而被阻止发布，但能力停用、版本失效、工具依赖和操作确认检查仍生效。队长／助理的内置能力不能添加到普通专家。
4. 保存和发布保留模型参数、能力绑定、操作开关、确认节点及完整输入输出约定。编辑草稿不改变已发布版本；刷新后读取同一浏览器存储；已发布历史快照不自动改写。
5. 读取旧纯聊天草稿时，仅在编辑副本中把旧 `attachments.count=0` 哨兵转换为可配置默认值；明确保存后才持久化。旧发布详情继续显示原快照值。
6. 延续未保存离开提醒、标签页暂存、存储失败保留输入、发布后读取失败只重读而不重复发布的行为。

## 接入边界

当前是浏览器本地配置与版本原型，没有接入真实 OIDC 登录、服务端管理鉴权、模型请求、Skill 加载、Tool 执行或 MCP 连接。能力与模型状态来自演示目录，不代表真实连通性。

后续运行服务应读取固定发布版本，验证用户与专家可用状态，按所选模型和输入输出约定运行，并执行绑定工具范围与确认规则。OIDC 身份仅用于识别用户，不能替代 MCP／业务服务的凭证和访问授权。

运行中心继续保留会话元信息、模型用量、异常和管理审计；本次没有伪造工具调用记录、真实执行结果或文件成果，也没有恢复旧业务任务流程。真实能力执行接入后，再从实际调用记录补充诊断信息。
