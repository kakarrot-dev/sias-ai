# 智能体输入与输出：配置与填写设计

> 后续归属调整（2026-09-16）：队长创建改为三步，用户表单与交付规范由专家团统一配置；普通专家仍独立配置。下文队长输入输出归属描述属于早期方案，以[已确认调整](2026-09-16-team-input-output-ownership.md)为准。

## 目标

管理员明确智能体需要什么材料、如何向用户收集、交付什么、怎样算完成。输入输出是普通专家和队长的独立配置步骤。专家团继续引用队长固定版本的约定。

## 页面与信息层级

- 创建：基本信息 → 工作能力 → 输入与输出 → 检查配置。已保存对象另外提供运行配置。
- 输入与输出内分为“输入与用户表单”“输出与完成条件”，避免把全部字段铺成一张长表。
- 输入页：开始方式 → 表单内容（标题、说明、字段、提交按钮）→ 资料类型与限制 → 缺失处理。右侧实时试填，可展开预览。
- 输出页：主要成果 + 附加成果 → 内容要求 / 模板引用 → 必需章节 / 字段与核对 → 完成条件。

## 字段与行为

复用 `InteractionConfig`，不建立第二套表单字段。新增内容全部可缺省，旧草稿、发布快照只在编辑保存时产生新版本。

| 约定 | 行为 |
|---|---|
| 开始方式 | 对话开始沿用旧入口字段；先填表单显示全部适用字段，支持选填与条件必填 |
| 表单文案 | 标题、说明、提交按钮；未设置时使用通用文案 |
| 字段 | 名称、类型、必填、条件、来源、说明、示例、默认值、范围及顺序 |
| 默认值 | 用户填写的非附件字段可设置；按同一类型与范围规则验证，示例不会被当成默认值 |
| 条件变化 | 隐藏不适用字段并清除旧回答；重新出现时重新填写 |
| 提交 | 必填、数值、选项、时间范围、附件限制均通过后显示输入摘要；可返回修改 |
| 附件 | 从输入类型推导允许格式；校验大小与数量；原型仅记录文件名和大小 |
| 缺失输入 | 请用户补充、等待材料、停止说明原因、转人工；转人工复用既有启用约束 |
| 输出组合 | 保留主要成果格式，按需追加其他格式；逐人文字交付保留已有逻辑 |
| 模板 | 记录已有模板的标识或路径引用；原型不声明已读取或验证模板 |
| 完成条件 | 成果校验通过 / 取得外部业务回执 / 用户验收；后两种另需结果证据，不以回复“完成”作为证据 |

## 验收与边界

1. 新建和编辑均能直接进入输入输出，旧深链接与参数保留。
2. 配置字段后，预览立即显示同一配置驱动的可填写表单。
3. 覆盖必填拦截、默认值、条件隐藏清理、附件超限、提交与重新填写。
4. 保存后重载配置、版本快照与发布差异包含新增约定。
5. 输出附加格式、模板、完成条件可保存，非法组合和缺少回执说明在配置校验中指出。
6. 类型检查、相关测试、构建及浏览器检查。当前是后台原型与用户表单预览，不接入真实模型、文件生成、OA 或生产用户端。

## 本次验证结果

- `admin:check` 通过；`admin:test` 共 18 个测试文件、288 项通过。覆盖旧配置兼容、默认值校验、条件字段清理、附件超限、原生日期输入事件、组合输出、回执证据约束、保存重载和发布差异。
- `admin:build` 通过；保留已有的大体积 bundle 提示，未在此任务扩展拆包工作。
- 实际浏览器验证：新建流程四步可达；后台文案和字段实时进入预览；空白提交提示缺项；输入主题与日期后进入填写摘要；默认值与填写说明即时生效；DOCX + PDF 与业务回执条件可组合配置。
- 1440×1000、1280×800 检查无横向溢出。右侧预览与完成条件面板避开固定导航，长表单在面板内滚动。浏览器控制台未出现警告或错误。
- 历史快照未改写；发布变更独立展示“完成条件与证据”；专家团摘要引用队长的完成条件。浏览器临时验收配置已放弃，保留原有智能体数据。
- 表单所采集的值仅用于当前预览校验；真实任务启动、模板解析、文件生成及回执核验仍需执行端接入。代码未提交或推送。
