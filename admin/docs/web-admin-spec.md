# 西亚斯数字员工平台管理系统 · 交互原型说明

> 用户与运行中心（2026-09-17，最新补充）：依据用户提供的 OIDC / Key / 模型与用量接入文档，同时保留平台统一 Key 和用户专属 Key。用户中心增加当前调用来源、接入状态及基本信息／模型接入／额度与用量详情；运行中心增加模型调用和来源、费用追溯，用量分为本平台调用与 Key 上游统计。OIDC 登录不代表业务授权或可调用模型；钱包、Key 额度、订阅额度、费用和实际费用分开。仅为脱敏数据驱动的前端原型，不实现后端、登录、Key 管理或模型请求。设计与验收见[双 Key 来源原型](audits/2026-09-17-oidc-user-run-design.md)。

> 能力上传（2026-09-17，最新补充）：能力中心通过“批量上传”添加 Skill、Tool、MCP，不提供表单创建。支持多个 Markdown / JSON 文件及 ZIP，解析预览后勾选有效项添加，失败和重复项单独提示；导入结果可在智能体中选择、保存和模拟发布。仅在当前浏览器解析与持久化，不增加后端或真实执行服务。格式、限制及验收见[能力批量上传原型](audits/2026-09-17-capability-batch-upload.md)。

> 模型目录（2026-09-17，最新补充）：新增“系统设置 → 模型管理”，管理自建中转站配置、同步模型列表、展示名称、能力和启停。创建专家时直接选择同一目录中启用且可用的模型，发布固定中转站标识与原始模型 ID。本轮为接入原型，真实接口信息尚未提供，同步使用明确标记的演示响应；当前规则及证据见[中转站模型目录](audits/2026-09-17-relay-model-catalog.md)。

> 单专家 MVP（2026-09-17，最新范围）：管理员创建／发布专家 → C 端统一登录 → 通过对话使用专家及其已配置能力。保留总览、智能体中心、能力中心、运行中心、用户中心、系统设置六个模块。专家配置分为基础与提示词、模型配置、执行能力、输入输出；取消、保存草稿和发布置于右上角，移除发布概览与聊天预览；输入输出仅保留两组格式选择；支持 Skill、内置 Tool、MCP 具体操作，保存和发布完整保留绑定版本、模型参数、执行前确认与输入输出格式。部门、复杂角色、数字助理、队长和专家团继续不开放。此前纯文字聊天范围已被本次要求替代；当前规则和验收以[专家能力配置记录](audits/2026-09-17-expert-capability-mvp.md)为准。

> 用户中心 MVP（2026-09-17，按最新要求收敛）：只保留 C 端用户列表、详情和账号启停。角色管理、权限查询、角色分配与逐个智能体授权暂不开放。正常用户登录后即可使用已发布且未停用的聊天智能体，无需单独授权；旧角色、授权及同步状态保留为历史数据，不再参与当前使用判断。真实 OIDC 尚未接入。当前规则及验收以[用户中心记录](audits/2026-09-17-c-user-center.md)为准。

> 运行中心调整（2026-09-17，展示沿用）：当前运行中心仍采用单智能体会话视图；本轮增加的是执行能力配置，真实执行记录待服务接入，运行中心统一为“会话记录、用量统计、管理审计”，智能体详情中的运行记录同步采用相同视图。移除办理任务、人工确认、执行结果及继续办理操作，旧数据不删除。会话详情仅展示元信息、回复状态、异常说明与用量，不展示聊天正文。当前会话及用量均为固定示例，管理审计读取浏览器内已有操作记录。以本文下方“纯聊天运行中心”说明为准。

## 交付范围

根据用户最新要求，仅制作可点击的西亚斯数字员工平台管理系统原型。使用 React、TypeScript、Vite，复用项目现有基础类型、员工字段校验和模型允许列表。不创建后端服务，不接入数据库、企业身份、桌面 Runtime、工具或真实模型。

当前六个一级模块：总览、智能体中心、能力中心、运行中心、用户中心、系统设置。默认打开专家列表。

## 2026-09-14 评审确认：专家配置与队长调度归属（已实现前端原型）

产品规则的唯一依据为[智能体中心管理模块需求与详细设计文档 v1.3](<../../obsidian-wiki/project/数字员工/详细设计/智能体中心管理模块 需求与详细设计文档.md>)。它包含对象归属、页面与字段、正常／异常交互、版本影响和 45 项前端验收案例；本文只同步实现边界。

- 专家（包括队长）使用基础信息、模型与提示词、工具、技能、对话体验五个区块；顶部锚点导航与整幅表单，滚动时同步标记当前区块，调试与保存／发布操作始终可达，发布前必填项显示红点与错误定位。独立输出编辑器删除，最终交付内容与格式只写在提示词。
- 专家团通过已有专家组队，选择其中一位为队长。团队目标、分工、调度步骤和交付规则属于队长专家提示词；团队只保存基本资料、专家固定版本引用和使用授权，并只读预览队长配置。
- 创建与配置不保留隐藏的高级设置：模型、工具身份与范围、团队能力与队长配置直接平铺。新专家移除分类、标签、渠道、知识库与 MCP 添加入口，原有扩展配置有可见的兼容编辑区；不在加载时删除历史数据。
- 提示词提供空白工作说明、办事咨询、材料核对、专家团队长四种模板；按职责／步骤／问题处理／交付编写，追加到同一提示词，待填写处直接提醒，模板与变量插入有 4000 字保护。保留全屏编辑和中文变量按钮；模型、回复语言、回答灵活度和对话轮次平铺。普通专家不展示“引用专家”，队长仅可选点名团队已选成员，组团发布不要求逐一点名。
- 工具和技能各有添加窗口，主表单只展示已选资源。两类选择各自暂存、确认后更新，取消不改表单；工具显示名称、启停、确认字段与权限直接可见。技能可排序、查看匹配版本的 SKILL 正文；版本继续固定，不自动采用全局最新版。已有权限、批准依据和运行保护保持，写动作不能关闭前置确认。
- 组团页不再提供独立的 `team.dispatch`、团队提示词或另一套模型／工具配置。修改调度规则进入队长专家，确认新版本只更新团队草稿引用，团队再次模拟发布后才采用。
- 名称自动生成内部拼音 key，首次保存后固定，界面不再要求填写标识。图标、简介、可见范围放在基础信息；开场白、问题排序、上传类型、过程显示与兜底话术放在对话体验。名称即可保存未完成专家草稿，已填内容仍校验；发布时校验完整性。
- 顶部“调试”单独打开窗口，直接使用当前未保存配置，关闭保留表单，重开清空临时对话。支持正常回复、无法回答、系统异常和工具确认／取消示意，不调用模型或工具，不把模拟通过当作真实质量证明。调试独立于发布的字段、引用与许可检查。
- 列表展示工具／技能数量与名称提示。新对象默认 Web；真实渠道分发、知识接入、长期记忆、灰度、归档、模板市场、团队流程画布或后端均未接入。

实施复用 `src/admin/campus/`、`PrototypeStore` 和浏览器 `campus` 数据分区、公共组件、`CapabilityPicker` 与统一 `capabilities.json`。工具参数示例补在统一目录，技能详情只读已有 SKILL 文件，不运行桌面 Runtime。仍使用现有 Hash 路由，已从真实 `#/agents` 入口验证。

旧 `entities`、校园草稿及发布快照保持读取；旧团队 `dispatch` 等仅作只读参考，不在加载时自动写入队长提示词。首次编辑旧专家时，原输出 requirements 迁入可见提示词，其他旧输出结构复位、非工具交付节点移除；保存后才写入，历史快照保持。系统设置增加专家分类维护，桌面端不在本轮范围。

## 历史流程记录（旧通用 Agent 模型）

- Agent：搜索筛选、新建与编辑，配置用途、角色、执行指令、模型、能力、记忆范围、输出与预算；保存草稿、预检、发布、查看历史快照、回退、启停。
- 专家组：按需选择协调者及多个业务成员；串行流程编辑器展示节点次序，点击节点编辑任务、输入和输出，增加、移除或排序成员；设置上下文策略、失败处理、预算与完成条件。
- 预检演示：字段缺失、用途错误、重复节点 ID、成员未发布或被停用、指令与配置的常见冲突均显示问题；编辑后旧预检失效。发布只生成浏览器内的版本快照，并记录成员版本。已发布对象的草稿修改不改写历史。
- 能力中心：关键词、Skill / Tool / MCP 类型与用途组合筛选；用途为信息检索、文档处理、内容分析、会议日程、消息通知、协作调度，支持一项能力多个用途，列表与详情展示同一目录的 `purposes`；未配置用途显示“未分类”，无结果可清除筛选。
- 运行中心：业务办理和普通聊天的示例记录、协作进度、异常详情、确认后继续演示；审计页记录当前原型配置操作。
- 用户与权限：示例成员搜索、授权弹窗、角色权限矩阵、组织目录及部门成员跳转。
- 系统设置：工作区资料保存、示例模型配置与启停、明确标记的连接检查演示。不采集密钥，不发出连接请求。

### 页面与字段

### 增删改查与状态规则

- 创建：继续使用五步向导；从草稿生成资产初始资料，进阶字段在创建后配置。
- 查询：常用目录、已归档、回收站三个视图；名称、说明、标签、负责人、ID 搜索；版本状态、用途、模型筛选；修改时间或名称排序与分页。用途、模型和能力列明确来自已保存草稿。
- 查看：概览可切换当前草稿与发布版本；详情分区为基本资料、指令与输入、模型与能力、输出与验收、运行与安全；查看完整快照、发布 ID、被引用关系与审计。
- 编辑：资产资料与行为草稿一次原子保存；发布版本保持不可变。归档和回收站对象允许切换各分区查看，禁止编辑、预检、发布和回退；恢复后继续编辑。
- 复制：明确选择已保存草稿或当前发布版本，生成独立新 ID；保留运行名称与指令，另设副本展示名，不复制发布历史、预检结论或被引用关系。
- 归档：移出常用目录并阻止新的成员选择及相关新发布；已有专家组发布快照继续保留，不自动停部署或取消运行。支持取消归档。
- 删除：仅无发布历史、无专家组草稿及历史版本引用的 Agent 可移入回收站；不提供永久清除。恢复时保留原 ID、字段及资产状态。
- 存储失败回滚当前事务，输入保留；保存、复制或生命周期操作成功但页面刷新失败时，只重试读取，不重复提交。
- 旧的目录停用标记仍兼容，并允许恢复旧配置的目录访问；与新资产归档、实际部署启停分开。

### 预检、预览与尚未接入的能力

预检检查结构化字段命名、重复、业务含义、部分保留身份字段及输出模式一致性。可保存待修订草稿；不满足规则不能发布。字段表是输入和输出 Schema 的唯一来源，生成指令与版本快照同步引用。

样例预演按已声明输入检查 JSON 对象、必填、类型及未知字段，显示按策略补充或停止；输出示例使用实际声明的字段生成固定样式。它不调用模型，不表示模型结果通过 Schema 或业务评测，也不构成服务端权限校验。

模型高级参数、提示词资产引用、独立知识库、逐工具身份及凭证绑定、真实审批、输出修复、执行限额、部署会话、运行控制、完整评测与 SDK 适配未接入；未将它们做成保存成功却无法落实的通用开关。实际执行前仍需落实字段字典中的适配能力登记和运行时验收。
